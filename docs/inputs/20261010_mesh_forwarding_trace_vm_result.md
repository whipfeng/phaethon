# VM 转发追踪验证记录

日期：2026-10-10

## 结果

VM 已部署包含 `mesh.forwarding-trace` 的程序，进程正常，开关可写入并生效。VM 对 `gg.phn` 的一次请求超时，主日志只出现 TCP forwarder 记录，未出现关联追踪事件。

## 结论

该结果不能用于判断 QG → JF → GG 的转发断点：VM 请求不是目标链路，且追踪只记录 IPv4 初始 TCP SYN 与 DNS UDP/53。VM 只作为二进制、配置和服务启动的烟测节点。

## 后续要求

实际定位必须在 QG、JF、GG 三端短时同步启用追踪，从进入 QG TUN 或旁路网关的客户端发起一次受控请求，并只按三端主日志的同一关联键判读首个缺失阶段。
