# 代理组编辑界面：保留弹窗而非平铺内联

## 元数据

- 文档类型：Decision（ADR）
- 日期：2026-07-15
- 所属项目：phaethon
- 状态：已采纳

## 1. 背景

订阅/代理组重构后，代理组的配置项被简化为：

- 名称、类型（select / best / load-balance）
- 可选的订阅源与过滤正则
- 手动成员（可包含 DIRECT、REJECT、嵌套代理组）
- 健康检查 URL 与间隔

在前端有两种编辑交互可选：

1. **保留 Group Modal**：点击“编辑”弹出独立表单。
2. **平铺内联编辑**：点击“编辑”在组卡片内部展开表单。

## 2. 决策

**保留弹窗编辑，并进一步简化弹窗内容；不改为内联编辑。**

理由：

- 代理组表单字段较多（尤其是手动成员双栏选择器），内联展开会把单个组卡片撑得很高，与下方成员表格混在一起，视觉焦点和滚动体验都会变差。
- 弹窗是成熟实现，改动风险小；重构的核心目标（成员平铺展示、active 与 membership 解耦）已经在卡片和成员表格中完成，不需要把编辑表单也平铺。
- “平铺”在本次重构中的含义是**成员列表平铺**，而非**编辑表单平铺**。

## 3. 后果

- 正面：列表页保持紧凑，编辑表单有独立空间，嵌套组选择器、健康检查等字段摆放更自然。
- 正面：无需重写事件绑定、表单验证和保存逻辑，减少引入新 bug 的可能。
- 负面：编辑仍需要二次点击打开弹窗；但成员表格本身已支持直接切换 active、测速等高频操作，弹窗只用于低频配置修改，影响有限。

## 4. 替代方案

### 4.1 平铺内联编辑

在组卡片内直接展开表单。优点是一次点击即可编辑；缺点是字段多导致卡片过高，且与成员表格同层级容易造成误解（用户分不清正在编辑的是配置还是成员）。

### 4.2 侧边栏 / 抽屉编辑

从右侧滑出编辑面板。空间比弹窗更充裕，但实现量接近重写，且在小屏下优势不明显。
