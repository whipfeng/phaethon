# P2P 连接状态抖动问题

**创建时间**: 2026-10-21
**状态**: 🔍 诊断中
**优先级**: 中

## 问题描述

创建新代理并开启 P2P 时，有概率（10-50%）出现连接不稳定：
- **表现**: P2P 状态小绿点持续闪烁
- **现象**: 感觉连接建立了又会断开，或者建立了多个连接
- **临时解决**: 重启服务后恢复正常
- **复现频率**: 中频（10-50%）

## 可能原因分析

### 1. OnStatusChange 回调频繁触发
- P2P 连接状态变化时会触发 OnStatusChange 回调
- 如果状态在 Connected/Disconnected 之间快速切换，会导致 UI 闪烁
- 已有 debounce 机制（task #494），但可能阈值设置不当

### 2. 多个 P2P 连接被创建
- 配置热加载时可能触发 P2P 连接重建
- 如果旧连接没有正确清理，可能导致多个连接并存
- 连接之间可能互相干扰，导致状态不稳定

### 3. 配置热加载与 P2P 建立的竞态
- 代理创建和 P2P 启用可能是异步操作
- 如果配置还未完全加载就开始建立 P2P 连接，可能导致失败
- 重试机制可能加剧问题

## 排查方向

### 代码检查
1. **P2P 连接建立流程**
   - 检查 `p2p/p2p.go` 中 StartPeer 的逻辑
   - 检查是否有重复创建连接的可能

2. **配置热加载处理**
   - 检查 `admin/admin.go` 中配置更新时的 P2P 处理
   - 检查是否正确等待配置加载完成

3. **OnStatusChange 回调**
   - 检查 debounce 机制的实现
   - 检查阈值设置是否合理

### 日志检查
1. **P2P 连接日志**

2. **配置加载日志**
   - 搜索 "config reload" 相关日志
   - 检查配置加载和 P2P 建立的时序

3. **状态变化日志**
   - 搜索 "OnStatusChange" 相关日志
   - 检查状态变化频率
